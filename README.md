1. 사전 준비 (Prerequisites)

   -스마트폰: 구글 플레이스토어 또는 앱스토어에서 Expo Go 앱을 설치합니다.

   -네트워크: 서버(PC)와 앱을 구동할 스마트폰이 반드시 동일한 Wi-Fi에 연결되어 있어야 합니다.

2. 백엔드(Backend) 서버 실행
   
   -먼저 데이터를 처리할 백엔드 서버를 구동합니다.

3. 프론트엔드(Frontend) 앱 실행

   -새 터미널 창을 열어 프론트엔드 설정을 진행합니다.

4. 앱 연결 (Scan QR)

   -npm start 실행 후 터미널(프롬프트) 창에 QR 코드가 나타납니다.

   -스마트폰에서 Expo Go 앱을 엽니다.

   -"Scan QR Code"를 선택하여 터미널의 QR 코드를 스캔합니다.

   -번들링(Building)이 완료될 때까지 잠시 기다리면 앱이 실행됩니다.
